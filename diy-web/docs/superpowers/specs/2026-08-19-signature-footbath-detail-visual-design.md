# 招牌草本沐足详情视觉设计

## 目标

为 `hxy-xiaoqi-90` 招牌草本沐足建立一套移动端详情视觉。视觉既要延续荷小悦人物 IP 和新中式水彩风格，也要帮助顾客快速理解它与普通沐足的差异：时间更充足、步骤更完整、照顾范围更全面。

## 已确认的内容边界

- 项目时长：90 分钟。
- 基础服务内容：草本泡脚、肩颈放松、足底按摩、走竹罐、腰背或腹部重点调理二选一、腿部按摩、草本热敷。
- 顾客可选择泡脚液、手法力度和重点调理方向。
- 不承诺治疗效果，不使用病症、器官、穴位、红痕等医疗化画面。
- 图片不生成中文、价格、时长、Logo 或水印；所有可变信息由前端渲染。

## 方案选择

采用四张独立场景图配合前端真实文字模块，不生成单张 AI 长海报。

这样可以：

- 保证中文、价格和项目规则准确；
- 单独替换质量不理想的板块；
- 控制移动端首屏和滚动加载体积；
- 让图片负责体验想象，文字负责理解与决策。

## 顾客决策顺序

1. **草本入足**：先建立温热、干净、有仪式感的第一印象。
2. **层层放松**：让顾客理解服务覆盖肩颈、足底和腿部，而不是普通泡脚。
3. **招牌步骤**：用竹罐、重点调理和热敷建立项目差异与价值感。
4. **放松收尾**：呈现体验后的松弛状态，促成选择。

对应前端标题：

- 一桶温热草本，慢慢泡开
- 从肩颈到腿足，层层放松
- 招牌步骤，更完整地照顾身体
- 90 分钟，留足时间慢下来

## 统一生成规范

- 模型：`gpt-image-2` 图生图。
- 参考图 1：荷小悦人物 IP 设定图，负责人物身份。
- 参考图 2：现有招牌草本沐足主图，负责画风、色彩和纸张质感。
- 画面比例：横向 3:2，原始生成 1536×1024。
- 每张只出现一个人物。
- 固定圆润儿童比例、棕色短发、浅绿色荷叶帽、米白上衣、绿色交领与短裤、棕色布鞋、黑色手绘勾线和低饱和水彩。
- 基础内容面纯白，背景仅使用很浅的水墨、荷叶、草本、云气或木器。
- 主色为深绿、浅荷叶绿、木色和暖白，暖金只作少量点缀。
- 不出现第二个人物、真人技师、医疗器械、人体红痕、诊疗暗示、文字、数字、Logo、水印、边框或拥挤背景。

## 图片处理与接入

- 保留原始 PNG 作为可追溯生成稿，不直接进入前端。
- 选定图统一缩放为约 960×640 WebP，质量约 78。
- 目标单张 70–130 KB；若复杂场景超过目标，优先减少无意义背景细节，而不是过度压缩主体。
- 文件命名：
  - `hxy-xiaoqi-90-detail-herbal.webp`
  - `hxy-xiaoqi-90-detail-release.webp`
  - `hxy-xiaoqi-90-detail-signature.webp`
  - `hxy-xiaoqi-90-detail-finish.webp`
- 四张图片位于详情页选项区之后、品牌故事之前，使用原生懒加载。
- 图片下方文案由前端 HTML 渲染，保证可访问性、可修改性和价格规则独立。

## 验收标准

- 四张图中的人物看起来是同一个荷小悦 IP。
- 顾客不读长文也能区分四个体验阶段。
- 不把草本沐足表现为医疗或治疗服务。
- 主图与详情图在色彩、勾线、留白和人物比例上保持一致。
- 手机端裁切不遮挡人物脸部、木桶、竹罐或热敷包等核心主体。
- 压缩后每张图片清晰且体积满足移动端目标。
- 详情图片加载失败时仍能通过文字理解项目，不影响选购和价格计算。
