# Herbal rounded font

Source: MaokenZhuyuanTi (猫啃珠圆体), published by 猫啃网, Little White Dog and 频凡.
Official font license: SIL Open Font License 1.1, https://www.maoken.com/freefonts/17948.html . See OFL.txt.
Distribution: @chinese-fonts/mkzyt 3.0.0 from registry.npmmirror.com; archive SHA1 488f1266984c3e60ffdb3e3fda84921b89226330.
Derived subset family: HxyHerbalRounded. Only the herbal selector character set is included; other characters use system fallback. Original copyright notices are retained in each font.
Rebuild: python scripts/subset-herbal-font.py output/font-source/package/dist (fonttools and brotli required).
The distribution package's MIT license covers its packaging, not the font; no package CSS is used.
