# 技师服务记录交互原型

范围：招牌草本泡（90 分钟）的服务前参考、本次记录、保存后历史回看。仅用于评审，不属于生产功能。

## 启动

在本 worktree 根目录运行：

```powershell
python -m http.server 5192 --bind 127.0.0.1 --directory prototypes/technician-service
```

打开 http://127.0.0.1:5192/ 。不需要安装前端依赖。

## 数据边界

- 所有顾客、记录和日期均为虚构示例；不要输入真实顾客信息。
- 保存只写入页面内存，刷新后重置；失败开关用于验证重试。
- 服务前参考为固定示例，不会自动聚合本次录入。
- 本人可见、跨技师授权均为产品规则展示，不代表后台权限已实现。
- 不调用 AI，不上传、不连接生产接口。

## 已执行的本地检查

- 390px 手机及 1280px 桌面浏览器截图；手机页面无水平溢出。
- 仅选沟通偏好可保存；模拟失败后输入保留并可重试。
- 纠正后旧版本保留。
- 部位条目未填反馈可保存；删除条目同时清理选择值。
- 内联 JavaScript 语法检查。

以上不是微信真机验收、跨技师权限验收或服务器持久化测试。
