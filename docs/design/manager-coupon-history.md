状态：已评审，执行中
日期：2026-11-12
范围：店长移动端券记录列表 + 详情
入口：经营 → 券记录；核销券 → 券记录

## 评审结论

| 问题 | 决定 |
|---|---|
| 统计卡名称 | 发券 |
| 链接生成是否算发券 | 不算；顾客实际领取/店长直接发券才计 1 张 |

| 按顾客搜索 | 不要 |

## 统计口径

- 发券：统计周期内实际创建的 `UserCoupon` 数量
- 核销：统计周期内 `manager_redeem_coupon` 审计事件数
- 待使用：统计周期内创建、当前 unused 的券
- 已过期：统计周期内创建、当前 expire 的 unused 券
- 生成链接：不计入发券，不进入时间线

## 事件

### 发券

来源：

- 顾客通过链接领取
- 店长直接按手机号发券

标题：

- `王女士领取半价券`
- `店长给王女士发券`

### 核销

来源：

- `manager_redeem_coupon` 审计
- 显示核销店长、时间

## 接口

```http
GET /api/v1/admin/v2/manager/coupons/history
  ?days=30
  &kind=all|issued|redeemed
  &limit=30
  &offset=0
```

响应：

```json
{
  "summary": { "issued": 11, "redeemed": 7, "unused": 4, "expired": 0 },
  "items": [],
  "next_offset": null
}
```

实现：

- 按当前登录店长的门店过滤
- `UserCoupon` + `AuditLog` 聚合
- 不发新表、不做迁移
- 不存 token

## 状态

- 加载：骨架/加载提示
- 空：近 N 天还没有券记录
- 错误：说明 + 重试
- 加载更多失败保留已加载内容
- 390px 无横向溢出
- 点击目标 ≥ 44px

## 非目标

- 不做按顾客搜索
- 不做导出
- 不做跨门店
- 不做发送批次/企业微信回执
- 不做详情核销快捷入口

## 验收

- 发券数 = 实际领取/直接发券数
- 链接生成不增加发券数
- 发券和核销筛选正确
- 直接发券和链接领取同时间线
- 已核销详情只读
- 只有本店数据
- 手机号脱敏
