## 使用方式

改 UI 前后分别截图，按页面逐项对比：

- 标题层级
- 主操作数量
- 卡片圆角/内边距
- 主色和金色用量
- 图片裁切
- 空/错/加载状态
- 390px 是否横向溢出

## 注意

- 会员截图使用临时测试账号，不包含真实顾客数据
- 截图只作为视觉参照，不替代真实设备验收
- 新基线必须记录生产 commit
- 不把测试 token 写入仓库

## 抓取注意

- 必须用 CDP `Emulation.setDeviceMetricsOverride` 设置 390 × 844 后再截图
- 直接用 headless `--window-size=390,844` 会被 DPI 缩放，出现假溢出
- 真实 390 视口下登录卡片宽 354px，左右各 18px，无横向溢出
