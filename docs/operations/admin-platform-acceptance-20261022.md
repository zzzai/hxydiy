## 4. 已上线能力

### 经营与订单

- 今日工作台汇总；
- 门店订单列表与详情；
- 订单派生工作状态：新订单 / 待服务 / 服务中 / 待离位 / 已完成 / 已取消；
- 超时 30 分钟未开始订单进入待处理；
- 超时订单可筛选查看；
- 服务位视图按沙发 / 房间分组。

### 评价

- 店长查看本店评价；
- 低分优先；
- 跟进状态与备注；
- 不能修改顾客原文；
- 评价跟进后工作台刷新；
- 订单详情可跳转对应评价；
- 企微评价卡片深链到具体评价。

### 待处理

- 顾客加选确认/拒绝；
- 低分评价待跟进；
- 超时订单；
- 「需处理」按异常项总数计算。

### 权限

- capability 矩阵区分门店运营、门店资源、目录上下架、总部主数据、评价跟进、员工账号等；
- 导航按 capability 过滤；
- 店长可上下架本店内容，不可编辑总部主数据；
- 店长不可见页面配置、优惠券、SCRM、员工账号、门店主数据；
- 旧权限 helper 委托 capability 矩阵。

### 企微通知

- 店长通知接收人不再排除有技师档案的店长；
- 生产目标：`zhangzhen`；
- 订单卡片打开订单；
- 评价卡片打开评价；
- 深链在 OAuth 过程中保留；
- 深链失效有明确提示。

## 6. 已知边界

1. 真实企业微信卡片在门店手机上的最终点击仍需现场验收。
2. 店长页面按钮级 capability 仍以现有页面模型和接口守卫为主，统一 hook 尚未覆盖所有页面。
3. 超时订单目前是提醒/筛选，不自动改变订单状态，也没有自动取消；这是有意的安全边界。
4. 总部管理员 `/access` 在生产冒烟中需要正常工作区选择令牌，未用多工作区登录流程重放。
5. 店员临时账号存在过期/停用状态，生产四角色冒烟不能替代每个真实员工登录。
6. 智慧宝物理资源仍由外部系统负责，DIY 不提供开位、离位、清洁动作。
