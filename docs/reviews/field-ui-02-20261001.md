## 已完成的页面路径

1. 顾客端以 375 视口选择项目并以匿名身份提交。
2. 前台以 390 视口登录，在“到店服务选单”确认选单。
3. 技师端以 390 视口登录，依次执行“开始服务”和“服务结束”。
4. 服务记录首次保存被合成 503 拦截后，页面保留已选内容并提示重试；第二次保存复用同一个幂等键并成功。
5. 技师在“服务记录”中看到本次记录和“更正本次记录”入口。
6. 第二个技师账号看不到第一位技师的本人记录。
7. 清理后再次从顾客页面进入，系统建立了不同于上一单的新草稿。

## 明确未通过页面完成的环节

前台“服务位看板”没有“确认离位”和“完成清洁”按钮。当前页面文案和代码约定均为智慧宝负责实际沙发开关，DIY 只记录服务开始和结束。因此本轮只为释放隔离合成服务位而调用本地接口，然后再从真实顾客页面验证新草稿；该接口调用不计作前台页面通过，也不应被描述为门店闭环已验收。
