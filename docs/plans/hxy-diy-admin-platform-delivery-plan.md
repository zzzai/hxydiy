# 荷小悦 DIY 管理后台与门店运营后台实施计划

## 1. 执行方式

- 每个阶段独立开发、测试、演示和验收；
- 只有功能、权限、隔离、故障演练和发布检查全部通过，阶段才可标记完成；
- 生产发布由管理后台窗口统一执行；
- 所有迁移先备份、预演、校验和灰度，保留回滚路径；
- 智慧宝 API 未提供前使用契约 Mock，不把猜测字段写入业务层。

## 2. 阶段计划

### 阶段 0：契约与基线

目标：消除现状、接口和生产风险的不确定性。

任务：

- 盘点现有生产 release、数据库、API、页面和历史兼容约束；
- 输出角色权限矩阵、数据字典、门店隔离规则和错误码；
- 向智慧宝索取 Base URL、认证、字段、分页、游标、频率和错误码；
- 建立智慧宝 Mock Server 与契约测试；
- 完成数据库备份恢复演练、Manifest 校验和回滚演练；
- 建立 API 版本与废弃清单。

退出条件：接口契约获业务方确认，Mock 测试通过，恢复演练有记录。

### 阶段 1：基础平台

任务：

- 补齐共享多店模型与 `store_id` 约束；
- 实现总部、店长、技师 RBAC；
- 实现主门店、授权门店和当前门店上下文；
- 实现后端强制隔离和越权测试；
- 实现不可变审计日志、幂等键和统一错误响应；
- 保持现有 API 向后兼容。

退出条件：跨店读写、导出、媒体和 API 直调越权测试全部通过。

### 阶段 2：总部目录与媒体

任务：

- 商品、服务项目、加项、规格和价格完整 CRUD；
- 草稿、发布、停用和门店发布范围；
- 店长只允许上架/下架；
- 阿里云 OSS 适配器、本地/MinIO 开发适配器；
- 上传、预览、替换、删除、排序、裁剪、压缩和引用保护；
- 历史价格、内容和媒体快照。

退出条件：总部编辑链路、店长限制、媒体安全和历史快照验收通过。

### 阶段 3：门店运营与智慧宝同步

任务：

- 门店、区域、房间、沙发、床位和服务位管理；
- 二维码生成、替换、作废和批量打印；
- DIY 服务位电子看板；
- 智慧宝拉取适配器、同步游标、本地快照和新鲜度告警；
- 明确区分 DIY 状态和智慧宝只读状态；
- 同步失败、重复数据、延迟和恢复测试。

退出条件：真实接口联调、字段对账、故障演练和状态来源验收通过。

### 阶段 4：技师工作台

任务：

- 手机登录和会话管理；
- 授权门店选择和当前门店切换；
- 服务单查看、确认服务和服务结束；
- 顾客画像最小必要展示；
- 当前服务门店写入画像；
- 自己记录可修改、店长受控更正；
- 弱网重试、幂等和审计。

退出条件：真实手机设备完成跨店查看、写入限制和断网恢复验收。

### 阶段 5：顾客闭环

任务：

- 扫码选位、会员识别和门店绑定；
- 会员最低价、非会员优惠券和价格解释；
- 选单提交、服务确认、服务结束和评价；
- 价格、项目、会员身份和媒体快照；
- 超时关闭与智慧宝履约单保护；
- 重复提交、并发占用和异常恢复。

退出条件：顾客端、技师端、店长端完整走通一条真实测试服务链路。

### 阶段 6：总部运营

任务：

- 跨店汇总、门店对比和项目/商品表现；
- 技师服务量和评价指标；
- 异步导出、脱敏、权限和下载审计；
- 查询索引、缓存和大数据量分页优化。

退出条件：报表口径与业务账本核对一致，导出权限测试通过。

### 阶段 7：生产验收与灰度

必须完成：

- 管理端单元、组件、路由和端到端测试；
- 后端 API、状态机、隔离、幂等、同步和迁移测试；
- 管理端生产构建；
- 数据库备份、恢复、Manifest 和健康检查；
- 100 店容量基线和关键接口性能测试；
- 断网、重复点击、并发、第三方超时和错误恢复演练；
- 单店现场验收；
- 灰度发布、监控观察和回滚验证。

## 3. 测试矩阵

### 权限

- 总部修改目录成功；店长修改目录返回 403；
- 店长只能访问绑定门店；
- 技师只能访问主门店和授权门店；
- 技师跨店写入非当前门店被拒绝；
- 导出和媒体 URL 继承相同隔离规则。

### 业务

- 任一店长/技师确认服务进入服务中；
- 重复确认/结束幂等；
- 结束后直接改价被拒绝；
- 店长更正保留前后值和原因；
- 超时关闭不覆盖智慧宝履约单；
- 会员缓存过期不自动给会员价；
- 历史快照不受调价影响。

### 媒体

- 非法格式、超尺寸、病毒扫描失败被拒绝；
- 上传失败可重试；
- 已引用资源不可直接删除；
- 跨店访问对象键被拒绝；
- CDN 凭证过期后不可下载。

### 可靠性

- 智慧宝 API 超时、限流、重复页和游标失效；
- Redis/任务队列短暂不可用；
- 数据库迁移失败回滚；
- 断网恢复后状态和命令不重复；
- 备份可恢复到 RPO/RTO 目标。

## 4. 发布门槛

每次发布必须记录：修改内容、涉及文件、测试结果、数据库备份、Manifest、线上健康检查、生产 release、是否发布、现场验收状态和未完成事项。未完成真实智慧宝联调、全量测试、备份、Manifest、健康检查或现场验收时，只能标记“本地完成”或“待现场验收”。

## 5. 风险与依赖

- 智慧宝 API 文档和测试账号是阶段 0 外部依赖；
- 阿里云 OSS Bucket、区域、CDN、密钥和生命周期策略需运维确认；
- 跨店技师授权需业务确认同城定义和撤销流程；
- 会员系统需确认缓存有效期和稳定外部会员 ID；
- 生产数据库备份和恢复演练必须由有权限人员执行；
- 任何新增前台、财务、预约、派单或收款需求必须单独评审，不得混入本计划。
