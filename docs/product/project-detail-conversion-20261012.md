## 结果与设计

用户后续纠正“偏好和加购应该靠前，DIY是重点”。当前顺序为“主图与项目简介/价格 → 服务偏好 → 可选加购 → 选购须知/服务说明/插画”：原主图和价格身份保留，一句具体选择建议保留在配置后，不裁切主图；配置区默认展开、可收起，不强迫顾客先阅读长说明。局部先选部位，再看补充须知。白色内容面、浅绿辅助、深绿主行动和少量金色价格提示不改；沿用系统字体，正文14px、次要说明至少12px，不新增装饰性动画、组件库或虚构评价。

保留所有长图，改为可展开的服务插画，而不是先滚过多张大图才能配置。14项分别写具体体验，删去通用模板重复句。局部推拿仅真实已选部位高亮并提供可读选中状态，空选显示项目总名与选择指引。套盒说明按实际整套价格/次数折算，仅供价格理解，不变为单次售卖。

## 必须保留的边界

- 不改项目名称、价格、团购、会员资格、次数/计价/免泡脚费规则、选项ID、必选默认值、确认负载、共享选单、服务位、二维码、报告/授权和后台API。
- 基础泡脚的“手法力度”只隐藏展示；既有后端必选校验与有效选择保持，不新增按摩服务。
- 未确认的时长不显示，不按旧编码或加购估时编造，也不把后台缺项变成顾客询问前台的任务。卫生措施、资格、预约/期限/退款、赠品或效果不作未经核实承诺；保留休闲服务/医疗边界。
- 服务号无seat浏览仍只读；“到店选项目”仍进入显式服务位核对，不自动占座、加单或远程下单。
- 不重画全部素材；精油开背若调整主图仅复用已存在的专属背部护理插画，不影响列表图或其他素材。
