# 技师学习与店长辅导正式接入 PRD

日期：2026-10-30。状态：代码接入、隔离验收；未提交、未合并、未发布。

## 目标与入口
在现有企微登录、员工身份、门店权限和工作台中承接日常学习。技师从工作台“本次学习”进入 `/technician/learning`；店长从门店工作台“团队学习”进入同一路径。角色由已有员工会话和服务端复验决定，不通过 URL 参数获取权限。沿用现有底部导航，不增加学习导航栏。

## 技师流程
优先显示有错题的课，其次未学完的课，再显示尚未开始的课。每页一个要点，每题一个情境；逐节保存至服务端。临时离开后按已保存章节续学，未提交选项仅存于当前浏览器会话，键包含门店、员工、角色、任务、课程版本与上次练习编号。

交卷前须读完全部要点、答完全部题目。服务端判分，交卷前不下发答案。错题显示本次选项、解释和参考答案；重练追加一份新成绩，保留此前成绩。答对练习不等于手法、实操或上岗资格达标。

## 店长流程
只显示本店人员；默认“需辅导”，另有“待学习”“全部”。同一人有多课时只计一个人。“需辅导”依据最近一次练习的错题，写过建议仍不会自动标记掌握。

“安排学习”展开本店技师和可安排课程；同一员工同一版本只有一个任务。打开任务能看已读进度、最近错题与历次成绩；追加具体辅导建议，技师下次打开本课即可读到。店长不能代读、代答、改分或删除历史。

文化辅导参考保留 6 个情境，作为带教材料，不作为已实施的店长考试或绩效扣分功能。

## 内容依据
企业文化采用 2026-09-08 PDF 元数据日期较新的品牌价值与行为体系，旧会议资料仅作补充。六课、十八道技师题；题干、答案、解释与来源文档绑定哈希。元数据日期不冒充制度生效日期。

首批内容为试讲版本。隔离库保留之前的服务意识、经络基础课与学习历史；本次正式候选内容包只包含六门文化课，不把未完成专业审核的经络手法课开放生产。

## 状态和失败恢复
- 阅读中：只记录已提交章节，不以停留时长自动判定学会。
- 待交卷：保留未提交选项，缺题时定位未答题。
- 保存中：即时禁用重复操作；失败保留原请求键，重试不重复写。
- 记录冲突：提示重新读取进度；回读最新状态后再操作，不覆盖店长建议或另一端已提交的成绩。
- 登录变化：丢弃旧身份响应；列表、动作及安排响应均核验返回身份。
- 功能关闭：工作台入口消失，直接打开只显示暂未开放。
- 无任务、无可辅导人员：使用真实空状态；不生成模拟待办。

## 数据与权限
沿用 `staff-learning-v1.md` 的三张增量表、版本、幂等、行锁及范围规则；本轮未修改 API 契约或迁移结构。课程内容与答案留在后端，前端不导入测试题库。

## 本批不包含
每日自动派课、AI 自动出题上线、外发企微消息、实操认证、绩效扣分、巡检、画像、风险解读及服务订单操作。其他预览文件与旧数据保留。
