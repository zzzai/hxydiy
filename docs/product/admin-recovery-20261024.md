## 目标和边界

总部维护服务标准及授权门店范围；店长处理本店选单、服务安排和异常；技师履约并记录。店长与技师共用移动工作台，按既有权限提供动作。总部后台为桌面任务工作区，不给店长塞桌面表格。
保留已有代码、旧数据、服务端价格、会员权益、幂等和门店隔离。智慧宝负责物理开房离位；DIY 选购与提交不以选座为前提。
不新增在线支付、退款、财务报表、外部营销消息、区域授权模型或数据库迁移。新增表、权限扩张和跨店数据能力须另行确认。

## A1 服务项目维护任务规范

角色：保持当前总部可编辑内容、门店仅允许现有启停动作的权限。不因 UI 调整放开门店改价格。
入口：服务项目列表 → 编辑指定项目。标题必须显示项目名称。主体按内容与图片、价格、展示设置分组；可选内容及发布检查分栏。
视觉：复用现有品牌变量；纯白内容、浅绿辅助、深绿主按钮；正文 14px，区块标题 16px；稳定双列输入网格，窄屏单列；不新增装饰图表或大型数字。
基本信息：统一按元填写，保留服务端分为单位的请求。保存失败留在原页、保留输入、可重试。修改后关闭需明确丢弃确认。切换标签不提交基本信息。
可选内容：中文类型和项目名称；关联项目显示带人民币单位的三档价，不显示 JSON/枚举；独立收费以元输入但请求仍为整数分。组/选项保存到目录草稿，需明确提示，不能伪称全部已发布。
读取状态：加载中、真正空目录、加载失败分开。失败不提供误导的新建空目录入口；只能先重试。旧请求不能覆盖切换后的项目。
发布：保留后端检查。检查失败不得显示检查通过或允许发布。价格预览失败单独提示，不显示假零元。示例组合必须说明只是计价示例，不是所有组合。
媒体：静态图片不拼 API 前缀；受保护媒体仍用现有身份。预览失败说明图片未加载并可重试，不清除已存图片、不自动重传。
预览：提供合成数据的真实组件演示；无生产 API、无真实账号/顾客；展示摘要不冒充完整顾客端计价或发布结果。

### 验收用例

1. 编辑已有项目，三档价为元；保存请求仍为正确整数分；原项目内容和门店 ID 不丢失。
2. 关联头疗显示中文价目，不出现价格 JSON、linked_project 等技术字段。
3. 专属收费 49.90 元提交 4990 分；0 元不误当缺失；空值和非法数字不转换成错误金额。
4. 目录读取失败 → 明确失败与重试，无空目录误导；重试成功显示真实组。
5. 保存失败保留输入；关闭未保存内容弹确认；取消关闭不丢内容。
6. 发布检查、价格预览分别失败时有正确状态；未通过检查不能发布。
7. 1440px 桌面、768px 平板、390px 窄屏可操作，无横向溢出；合成浏览器操作零生产请求。
8. 既有目录/项目/权限相关测试通过；构建绑定源码哈希；预览不等于生产上线。
