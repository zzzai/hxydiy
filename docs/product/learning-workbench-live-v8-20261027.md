# 技师与店长学习闭环 V8

2026-10-27。承接已认可 V7，同一个企微工作台中按身份呈现，不增加独立培训 App。当前交付为隔离联调预览，不发布。

## 要解决的门店问题
技师需要能看懂、记住并用于当次服务；店长需要知道谁尚未学、错在哪里、是否已辅导。避免把打开页面、点完成或练习全对伪装成会操作。订单当前不要求店长处理；保留评价跟进、重点现拍巡检与门店现场入口，不把这些功能复制成另一套培训工作台。

## 本批真实流程
1. 店长在工作台点“团队学习”，展开“安排学习”，选择本店技师和课程版本。
2. 技师在今日服务点“本次学习”，逐节阅读，再提交完整练习。
3. 后台计算结果；错题显示解析，允许复习重做，每次结果保留。
4. 店长从“需跟进”进入具体人员及课程，看阅读进度、历次练习和错题，追加具体辅导建议。
5. 技师下次进入看到建议与自己的记录；刷新/退出再进入从后台回读。

不新增底部导航。学习入口只是一行摘要；“需跟进”是学习状态，不自动等同投诉责任或绩效扣分。不能仅凭点击阅读证明理解。本批尚无排班/日历自动派课、截止日期、定时催学或外发消息，不展示这些入口。

## 首批素材
- S01 服务意识：把顾客本次要求听清、落实、反馈；3 节、6 道情境题。
- M01 经络穴位基础：先认识名称与编码、辨别知识材料适用边界；3 节、6 道辨识题。
- 两课均为 pilot-v1 试学素材。沿用 V7 来源清单，不新增穴位定位、按压深度/力度、治疗承诺或生成医学解剖图。
- 经络穴位定位、手法实操和正式考试必须在后续经专业审核再发布。AI 不评实操视频。店长实操考评及客诉责任机制不在本次数据库/页面实现范围内。

## 页面设计
纯白内容、浅绿辅助、深绿主操作；正常字号与触控面积。技师突出一课一步的“继续学习”；店长先看未完成和需复习，再看具体错题。服务与学习共用身份、门店、返回路径。失败显示可理解原因并保留当前操作，重复安排/提交不生成重复记录。
