# 技师服务笔记

状态：开发验证中，未发布。本文件取代本轮结果分支方案，不覆盖已有数据契约。

## 要解决的问题

服务结束后，技师需要保留能指导下一次服务的事实，而不是填完整画像问卷。核心记录是顾客明确提出的要求、本次有效或无效的调整、仍需确认的事项。未提及不等于没有，不记录推断出的满意度。

## 交互

- 首屏可直接写最多 200 字，不先选择服务结果，不强制选标签。
- 沟通、力度、温度、重点及避让分别成组并直接呈现，不混合不同含义、不折叠常用内容。
- 顾客反馈与下次安排可以留空。无补充是独立完成状态，不代表满意。
- 身体补充先选择带左右名称的部位，再在一页填写自述情况、当前状态与本次处理；人体图仅为辅助定位，不作为必经操作。
- 关闭未保存笔记须明确选择继续填写或放弃。网络失败保留内容，相同载荷重试沿用幂等键。
- 不用标签数量、字数衡量绩效；避免为完成考核编造内容。

## 数据边界

沿用现有 v5 结构与权限，不增加疾病画像、营销分群或身份关联。文字仅技师本人历史可见，不承诺跨技师共享。顾客确认不自动扩张文字权限。身体记录仅保留顾客自述且下次再确认，不作诊断。

## 验收

1. 仅填写文字或仅选择聊天偏好均可保存；全空只能选择无补充。
2. 无补充与实际内容互斥，不写成顾客满意。
3. 保存失败可重试；修改后不会复用旧载荷；关闭不误丢笔记。
4. 身体记录支持左右、多部位、编辑与清除；不强制操作人体图。
5. 小屏没有横向溢出，底部按钮不遮挡最后一项，键盘与焦点可用。
6. 历史返回真实记录；权限范围不因界面改版扩大。

自动化通过不等于微信真机和门店现场验收。发布状态以发布报告为准。
