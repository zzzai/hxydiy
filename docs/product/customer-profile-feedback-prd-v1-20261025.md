# 顾客个人中心与评价返回优化

状态：用户已批准本批发布；执行记录以 CI、服务器验证与生产发布证据为准。

## 场景与结果

顾客从紫薇壹号店独立二维码提交到店评价，成功页停留并给出两个清楚的去向。“返回菜单”直接打开 `?store=1&view=menu&page=projects`；“查看检测报告”进入 `?store=1&view=reports`，按既有本人登录规则查看。不增加导航页或强制选座，也不自动跳转。

个人中心保留突出的会员身份大卡片。常用入口两行三列：服务记录、待评价、检测报告；服务号、联系门店、超级星期二。服务记录默认收起，点击后展开、滚动并聚焦列表，也可收起。每条可评价服务有明确“去评价”；无可评价记录时显示明确空态。

## 视觉与信息

沿用已确认品牌规范：纯白内容、浅绿辅助、艾木绿主操作；正文层级16/14/12px，图标22px，点击区域不小于44px。会员大卡使用白底与清晰绿边框，卡种标识突出；去掉巨型累计数字和重复推广卡。会员信息保留来源真实的昵称、脱敏手机、权益和有效期，不把储值会员一律写为年度会员。点击服务记录后展示最近3条，按需加载更多；接口只返回最近50条时明确标注范围，不能当作终身累计或总数。

## 数据与交互

- 不删除、不改写张震或其他顾客的历史数据；本次不把测试账号数据当作真实经营指标。精确测试记录清理由独立清单另行处理。
- 评价对象仍由服务器返回的本人选单与可评价标志决定；匿名到店评价不冒充技师服务评价。
- 评价提交中防重复点击；失败保留评分和建议并显示可理解原因；成功明确反馈并刷新待评价状态。
- 退出、换号及迟到响应不得显示上一账户的服务或打开的评价；会员仍不请求无权限的优惠券接口。
- 不改价格、权益、数据库、真实顾客记录、菜单选购与座位规则。

## 验收

真实React行为测试覆盖直达菜单、待评价焦点/筛选、空态、评价成功/失败/重试/重复点击、换号隔离。隔离预览只用合成数据并拦截所有业务请求；375/390px检查溢出、首屏层级、触达和完整点击流程。保留旧修改；通过 CI 与服务器验证后发布，人工真机验收单列。
