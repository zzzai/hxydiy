# BR-04 门店生命周期与开业 PRD

关联：[README](README.md)、[catalog-publication](catalog-publication.md)、[governance-permissions](governance-permissions.md)
优先级：P0
当前实现：基础 CRUD（门店主数据页），缺生命周期和开业校验

## 1. 执行摘要

门店不是一条 CRUD 记录，而是一个有开业准备、试营业、营业、暂停、停业、闭店的生命周期对象。系统必须在门店未就绪时阻止交易，在门店暂停/停业时给出存量业务处置方案。

## 2. 问题与目标

### 已确认问题

- 门店 `status` 目前只是字段，不阻断顾客端和后台交易；
- 新店开业靠人工检查，容易漏项目、页面、人员、服务位；
- 停业/暂停没有停售、预约、已有订单的处理规则；
- 地址/城市/营业时间变更没有版本和审计；
- 门店编码全局唯一但缺少改名/迁移规则。

### 目标

1. 门店状态成为业务闸门；
2. 开业前有可验收清单；
3. 暂停/停业有明确影响范围；
4. 所有关键变更留历史版本。

## 3. 角色与范围

| 角色 | 权限 |
|---|---|
| 总部管理员 | 创建、编辑、暂停、停业、闭店、恢复 |
| 总部运营 | 查看、提交开业检查、维护营业时间 |
| 店长 | 查看本店状态，维护本店营业时间和页面，不可改主体 |
| 顾客 | 只看到营业中/可预约门店 |

## 4. 门店状态机

```text
draft → preparing → trial_open → open ⇄ suspended → closed
```

| 状态 | 顾客可访问 | 可下单 | 可服务 | 说明 |
|---|---|---|---|---|
| draft | 否 | 否 | 否 | 建档 |
| preparing | 否 | 否 | 否 | 装修/配置 |
| trial_open | 是（标注试营业） | 是 | 是 | 试营业 |
| open | 是 | 是 | 是 | 正常 |
| suspended | 展示暂停 | 否（已有订单可继续） | 是（存量） | 暂停新交易 |
| closed | 否 | 否 | 否 | 闭店归档 |

规则：

- 只有 `open/trial_open` 接受新订单；
- `suspended` 必须填写原因、影响范围、预计恢复时间；
- `closed` 前必须完成未完成订单/退款/结算；
- 状态变更必须审计并通知相关角色；
- 不允许硬删除门店。

## 5. 开业检查清单

开业前必须完成：

- [ ] 门店名称、编码、城市、地址、经纬度、电话、营业时间；
- [ ] 负责人/店长绑定；
- [ ] 至少一个技师账号可用；
- [ ] 至少一个服务位启用；
- [ ] 至少一个项目已上架且价格有效；
- [ ] 至少一个加项/商品配置完成（按业务）；
- [ ] 顾客入口页面可访问；
- [ ] 支付/结算方式已配置（线下也需登记）；
- [ ] 隐私/会员/评价文案确认；
- [ ] 总部验收人和验收时间。

检查未通过时允许保存 `preparing`，不允许进入 `open`。

## 6. 核心流程

### 6.1 新店创建

1. 总部创建门店，生成门店编码；
2. 填写主体资料；
3. 绑定负责人/店长；
4. 配置服务位、项目、页面、员工；
5. 提交开业检查；
6. 总部验收；
7. 进入试营业/正式营业。

### 6.2 暂停营业

1. 总部选择暂停原因和范围；
2. 系统阻止新订单/新预约；
3. 已有订单允许继续完成；
4. 顾客端展示暂停说明；
5. 恢复营业需再次确认。

### 6.3 闭店

1. 检查未完成订单、未结算、未退款；
2. 停止新交易；
3. 导出/归档数据；
4. 关闭门店，保留历史访问权限；
5. 撤销员工/技师授权。

## 7. 权限与审计

- 创建/状态变更仅总部管理员；
- 店长只能改允许字段（营业时间、页面文案、联系电话，需审批）；
- 编码不可变；
- 变更前后值、操作人、原因必须入审计；
- 跨店复制配置必须记录来源门店。

## 8. 指标

- 开业准备周期；
- 检查一次通过率；
- 营业中门店数/暂停数；
- 停业影响订单数；
- 门店配置完整度；
- 门店编码/地址重复率。

## 9. 验收标准

- [ ] 非 `open/trial_open` 门店无法创建新订单；
- [ ] 暂停门店已有订单仍可完成；
- [ ] 未通过开业检查不能进入营业；
- [ ] 闭店前阻止有未完成结算的门店关闭；
- [ ] 状态变更写审计并通知；
- [ ] 门店编码不可变；
- [ ] 总部/店长字段权限正确。

## 10. 当前实现差距

- 已实现：非 `open/trial_open` 门店拒绝新建选单、下单、扫码入座，顾客门店列表只返回营业中门店；
- 门店编辑已记录 before/after 审计；
- 还没有开业检查清单和状态转换动作；
- 地址/营业时间变更无版本；
- 闭店无检查；
- 总部跨店经营视图缺失（见 BR-09）。

## 11. 非目标与开放问题

非目标：首版不做加盟商结算/合同管理。

🔵 OQ：试营业是否允许会员价/优惠券？
🔵 OQ：暂停营业时已有预约是否自动取消？
🔶 假设：门店状态由总部管理员维护，店长只读。
