## 3. 本轮实现内容

1. `/admin/v2/manager/workbench` 增加：
   - `waiting_service`：待服务占用数；
   - `unassigned_service`：待服务且未分配技师的占用数；
   - `completed_today`：今日已结束服务数；
   - `attention.unassigned_service`：待办入口。
2. 店长移动端概览改为“今日订单 / 待服务 / 服务中 / 已完成 / 需处理”，不再突出待结账。
3. 店长待处理页增加“待服务订单尚未分配技师”，说明由店长现场核对服务位并安排，跳转座位视图。
4. 技师服务看板增加动作：
   - `waiting_service`：确认接单并开始服务（写实际技师归属、开始时间、预计结束时间）；
   - `in_service`：结束服务（写结束时间、进入待离位）；
   - 动作使用幂等键，成功后刷新看板；重复命令由后端幂等返回。
5. 店长待处理页接入异常队列：漏单、选单缺订单、金额不一致以业务语言展示，显示处理人和截止，可“确认知悉”，确认即写处理人和时间。
6. 清理“系统自动处理确认/结束”的过时文案，改为“操作会同步到店长工作台”。
7. 保留价格、会员权益、权限、门店隔离、重复提交保护；未新增迁移、权限或外部消息。

## 6. 真机验收清单（交给人）

前置：合成门店、合成技师、合成顾客/选单；不影响真实顾客。

1. 技师登录移动端，看到待服务订单；
2. 点击“确认接单并开始服务”，确认按钮只提交一次，刷新后状态为服务中；
3. 店长移动端同时打开工作台，确认“服务中 +1、待服务 -1”；
4. 技师点击“结束服务”，状态进入待离位/已完成口径；
5. 店长工作台确认“已完成 +1、服务中 -1”；
6. 店长待处理页看到“未分配技师”项，点击进入座位视图；
7. 弱网/重复点击：确认、结束各只产生一条状态转移和一条审计；
8. 断网重试不产生第二次状态变化。
