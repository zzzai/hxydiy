# 企业文化学习 V28 隔离专题预览

## 目标与范围
将 2026-10-30 题库 v2 接入既有学习真实接口。按用户最新日期优先指令，以 2026-09-08 生成的品牌行为文件为主要依据，采用正直、匠心、效率、共赢，以及轻松、温暖、专业、安心。不把旧会议价格当现价。

技师 6 课，每课 3 个服务要点、3 道情境题；服务端保存阅读进度、判分、保留历次练习并返回错题解析。店长查看本店学习任务并追加辅导建议；另 6 道店长题为可展开的带教参考，不伪装为已经实现的店长考试或认证。

## 兼容和边界
仅新增 V28 测试预览、文化课程 fixture 与本说明；不修改旧预览、既有课程版本、业务 API 或迁移。6 个新的 culture-hxy-* 课程采用独立版本 20260908-v2-pilot，运行于专用测试数据库。专题前端只显示这批课程，旧学习记录原样保留；生产开关不变。

复用 staff-learning-v1 的权限、幂等、课程 SHA、服务端判分和辅导接口，不改变跨端契约。标准答案仅存在后端课程 fixture，技师未交卷前 bootstrap 不返回答案和解析；店长公开辅导参考与技师题目独立。参考资料不链接本机磁盘或虚假外网地址。
