# 每日学习闭环实施与验收

## 目标与范围
复用已发布12课36题，店长按北京时间日期和截止时间安排本店技师学习；技师阅读答题，店长查看未完成/错题并记录辅导，技师复练。默认当天23:59，可安排未来30天。过期允许补学，保留逾期事实。未来日期不能提前提交。本轮不自动派课、外发消息、生成题目或认定实操资质。

## 已确认实现选择
现有唯一员工/课程任务作为长期课程档案；每日安排作为新的assign事件，附daily_plan日期与截止时间。每日阅读、答卷、辅导事件用daily_plan_id关联。每日视图按事件派生，旧事件/课程/答卷不覆盖，已有无日期课程单独保留历史入口。不改表、不迁移、不回填。重复同人同课同日返回已有安排；截止时间冲突明确拒绝。沿用身份/门店即时复验、任务版本和请求幂等。单次安排一位技师的一课，降低错误派发范围。

## 状态与统计
每日任务显示未开始、学习中、待答题、待辅导、待复练、已完成；全题答对且提交晚于最近辅导才完成。未到期/逾期与学习状态独立。新日期必须完成当日阅读/答题，旧成绩不能抵今天任务。店长按日期查看安排、完成、未完成、错题/待复练；可单独查看跨日期逾期未完成。未安排人员不计为已完成。统计任务数与人数明确区分。
