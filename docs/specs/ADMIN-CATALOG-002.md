- Feature ID：`ADMIN-CATALOG-002`
- 当前状态：`Deployed`

- 执行窗口：管理后台
- 权威 PRD / contract：`docs/product/hxy-diy-admin-platform-prd.md`、`docs/contracts/admin-catalog-openapi-v1.md`

## 业务目标

总部可以在现有商品管理中维护门店价、可选会员价、展示顺序、主图和文字详情；已发布商品按后台顺序出现在公开目录。店长继续只能上下架本店已下发商品。

## 非目标

- 不建设库存、采购、在线支付、退款、自提或配送履约。
- 不改变顾客端商品下单链路；本轮只提供目录数据。
- 不改变项目定价、加项定价、门店隔离或既有历史数据。
- 生产发布与门店现场写入验收不作为功能实现的同一完成证据，必须分别记录。

## 业务规则

- `price_cents` 为门店价且不得小于零。
- `member_price_cents` 可为空；有值时不得小于零或高于门店价。
- `display_order` 为非负整数，公开目录按其升序、再按商品 ID 升序输出。
- `detail_modules` 首期保存受控的文字或图片详情模块；空数组表示暂无详情。
- 总部可维护完整主数据并强制下线；店长仅可在 `candidate`、`published`、`inactive` 间切换，不得恢复 `archived`。
- 创建和修改继续写入目标门店审计；旧 POST 更新路径保持兼容。

## API 与数据契约

- 管理端商品读写新增 `member_price_cents`、`display_order`、`detail_modules`。
- PATCH 显式传入 `member_price_cents: null` 表示清除会员价。
- 公开商品列表返回相同展示字段，但仍只返回 `published` 商品。
- OpenAPI 快照与生成的 TypeScript 类型必须随实现同步更新。

## 跨端影响

| 端/组件 | 是否涉及 | 责任与边界 |
|---|---|---|
| 后端与 OpenAPI | 是 | 数据迁移、校验、排序和机器契约 |
