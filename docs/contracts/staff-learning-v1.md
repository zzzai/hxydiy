# 员工学习接口契约 v1

状态：2026-10-27 隔离实现；未合并、未启用生产。关联 PRD：../product/learning-workbench-live-v8-20261027.md。

## 身份与范围
沿用现有员工 JWT 和服务端即时身份复验，不新增登录方式。店长只能访问当前门店；技师只读写本人学习任务，仍须有同店有效技师档案。总部身份没有学习全店查询入口。拒绝请求参数覆盖门店/身份；停用账号、跨店访问与角色越权拒绝。店长不能代读、代答、改分，技师不能安排课程或写店长建议。

## 接口
前缀 /api/v1/staff-learning。所有接口要求员工认证。
- GET /status：返回 enabled；不启用时不查询学习表。
- GET /bootstrap：actor、assignments、courses、roster、assignableCourses。技师只有本人任务及对应课程，roster/assignableCourses 为空；店长只有本店任务和有效本店技师名单。
- POST /assignments：staff_id、course_id、course_version、request_id。仅店长；一个门店同一员工同一课程版本只生成一个任务。
- POST /assignments/{id}/actions：kind、request_id、expected_revision。mark_section 仅带 section_id；submit 仅带 answers；follow_up 仅带 note。拒绝多余字段及客户端分数。

课程公开题目只有 id/prompt/choices，不包含标准答案和解析。交卷后仅通过本人任务或本店店长可见的 attempt.review 返回标准答案、解析。判分由服务端进行；练习得分不是实操达标或项目上岗资格。

## 保存与冲突
员工行及任务行加锁；版本匹配后追加事件并递增 revision。request_id 在门店、执行员工范围唯一，精确重复请求不重复写；同键异内容返回 409。先校验当前身份和范围，再识别重复请求，不能通过重放绕开权限。重复成功请求回读当前快照，不保证返回最初时刻的旧快照。
两个店长同时给同一员工安排同一课程版本，由唯一约束兜底，只生成一个任务。答题必须完整、整数选项有效且逐节学习完成；重复交卷只追加一次尝试。新一次练习保留旧成绩。店长建议只追加，不覆盖练习或他人的意见。

## 课程与状态
课程版本内容与 SHA256 绑定，内容漂移返回冲突。pilot 仅 local/test 可用；published 还要求非空审核依据。retired 课程历史只读，不接受新动作。正式内容通过 `scripts/publish_staff_learning.py` 精确 SHA 预览后发布或停用；不提供页面改题或专业实操认证。批准引用记录用户的内容投产指令，不等同医疗专业审核。
学习状态由阅读节数和历次练习推导：未开始、学习中、已读待练、需复习、练习全对。没有以页面停留时间、勾选或练习全对自动授予实操资格。客户端不持久保存学习记录，刷新从服务端回读。

## 数据存储
仅新增 learning_course_versions、staff_learning_assignments、staff_learning_events；外键引用 stores/staff，不改订单、会员、余额、服务记录。事件记录执行人、内容、请求摘要、任务版本和时间；无修改/删除事件接口。

## 开关与迁移
后端 STAFF_LEARNING_ENABLED 默认 false，前端 VITE_STAFF_LEARNING_ENABLED 默认不启用；两个开关都开启才正式可用。本次预览通过专用测试入口注入组件，生产默认入口不变。
迁移 20261027_staff_learning 接在 20261026_coupon_budget 后，仅建三表及索引。具体投产/回退步骤见 PRD；用户 2026-11-02 已明确授权真实备份和隔离恢复验证后的三表增量迁移、12课36题导入与启用；未完成验证不得直接迁移。
