# 顾客浏览器身份与选单价格契约

## 身份边界

- `hxy_browser_token` 是 HttpOnly 匿名浏览器凭证，只用于识别同一匿名浏览器，不代表手机号账号或会员身份。
- 手机号登录后，历史匿名业务记录可以归入手机号账号；浏览器匿名凭证本身不得永久改绑到自然人。
- 顾客端只有在携带有效登录令牌并显式绑定当前选单后，当前选单才按账号会员状态报价。
- 后端读取到历史上已绑定手机号账号的浏览器凭证时，必须为该浏览器轮换新的匿名用户并继续使用原 Cookie 凭证；不得继承会员价格。

## 多次提交价格

- 顾客每次追加提交都发送当前整单项目，后端按本次完整项目集合重算并覆盖当前会话价格快照。
- `store_total_cents` 和 `member_total_cents` 分别是整单门店价与整单会员价；`payable_total_cents` 仅表示服务端当前绑定身份的应付价格带。
- 顾客端显示“门店价”时必须读取 `store_total_cents`，显示“会员价”时必须读取 `member_total_cents`，不得把 `payable_total_cents` 换标签展示。
- 无促销的历史异常快照允许以前端整单小计或价格明细合计兜底；有促销时必须保留对应价格带的服务端最终总价。

## 回归要求

- 覆盖匿名首次提交、返回菜单、追加提交和整单总价累加。
- 覆盖历史浏览器凭证误绑会员账号后的自动匿名化与门店价恢复。
- 覆盖登录后当前选单显式绑定会员身份；不得依赖 `localStorage` 决定服务端身份。
