# 管理端媒体交付 v1

## 稳定引用

`POST /api/v1/admin/media` 与媒体列表的 `url` 统一返回稳定的受控内容地址：

```text
/api/v1/admin/media/{media_id}/content
```

项目、商品和加项表单只能保存该稳定地址，不得保存对象存储或 CDN 的临时签名 URL。

上传仅接受 JPG/JPEG、PNG、WebP 或 GIF；声明的 MIME 类型、文件扩展名与经服务端解析的实际图像格式必须对应。单文件上限为 5MB，默认最大像素数为 20,000,000（可由部署环境配置）。上传审计记录字节数与解析出的宽高。

## 读取与权限

`GET /api/v1/admin/media/{media_id}/content` 继续校验当前员工的门店范围和软删除状态。对象存储支持签名 URL 时，服务端在该请求中生成并以跳转返回短期 URL；本地存储继续代理内容。该实现不扩大媒体读取权限。

## 删除与引用保护

`DELETE /api/v1/admin/media/{media_id}` 先在同门店已发布的项目、加项和商品中检查稳定内容地址；项目的详情模块也参与检查。仍被任一已发布目录引用时返回 `409 MEDIA_IN_USE`，调用方必须先解除该引用。

通过检查后只设置媒体元数据的 `deleted_at` 并记录审计，不在请求内物理删除对象存储文件。对象清理、保留期和恢复入口须在后续独立契约中一起交付，避免“软删除”无法恢复。

本期不处理既有目录中已经保存的外部或过期 URL，不增加迁移、裁剪、压缩、病毒扫描、媒体排序或历史订单快照推断。
