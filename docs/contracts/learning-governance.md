# 学习治理只读总览契约

日期：2026-11-13

## 范围

- `GET /admin/v2/learning/overview` 为总部/本店管理员提供只读课程版本、员工学习任务和 AI 使用审计。
- 不创建任务、不提交答案、不评分、不自动发证、不自动安排课程、不调用模型、不发送消息。
- 课程版本按 `code + version` 独立展示，旧版本和旧成绩不覆盖；`content_sha256` 不一致时标记内容待核验，继续阻止新学习。
- 返回课程标题、章节标题、题目数量、状态、适用范围说明和已安排/已提交数量；不返回题目答案、解析、顾客姓名、手机号、健康情况、评价正文或服务记录正文。
- AI 指标只来自既有 AuditLog：动作 `learning_ai_coach` / `learning_ai_weekly_plan`，状态 success/error，`latency_ms` 和 `usage.total_tokens`。不虚构费用金额，不把模型输出当医疗或能力结论。
- 学习开关或 AI 配置未就绪时，页面显示真实状态并保留可用审计读取，不伪造“已启用”。
