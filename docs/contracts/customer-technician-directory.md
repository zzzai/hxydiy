# 顾客端本店技师

顾客可从门店菜单或单份项目的服务技师区进入本店技师名单。浏览、切换主页和查看工作相册均为只读操作。项目下的点名仅回填当前这一份草稿，仍须确认项目、提交选单并由店长确认。

## 公开资料

`GET /api/v1/stores/{store_id}/technicians` 仅接受营业和试营业门店。返回 `items`，每条包含门店内稳定的 `key`、公开称呼、可选的已确认从业时间、肖像、服务标签、介绍、工作照及本店公开项目 ID。手机号、员工登录名、入职日期、佣金、内部备注和未公开媒体均不投影。从业年限以门店确认的资料为准。没有真实照片、评价、从业年限或服务标签时，相应内容留空。

门店可在版本化的 `hxy-server/content/public-technicians.json` 中维护已经确认用于顾客展示的内容，按完整 `store_code` 分组。肖像和工作照仅使用该门店 `diy-web/public/assets/technicians/<store_code>/` 下获准公开的图片。更新图片使用新的文件名。没有明确绑定的公开工号可以展示，`technician_id` 为 null，两份项目列表为空。工号保留前导零。配置绑定必须指向同店正式技师，停用、离职、模拟和管理账号均不进入顾客名单。首次发布的华富六份资料只含工号和已确认从业时间。

正式账号的 `project_ids` 取自已登记技能与本店独立公开项目的交集。只有符合原点名条件的项目才进入 `requestable_project_ids`。休班技师可查看公开资料，点名集合为空。点名会再查询该项目的实时可选名单，保存和提交沿用服务端的逐份资格校验。可提交点名不代表已经排钟。门店名册中的工号与业务技师 ID 不做数值匹配。
