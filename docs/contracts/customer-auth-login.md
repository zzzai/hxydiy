# 顾客登录环境边界

Feature ID：SAFE-01；更新日期：2026-10-01。

- `POST /api/v1/auth/login` 的 `dev_` 模拟身份仅允许 `environment=local` 或 `test` 且未配置微信小程序密钥时使用。
- production、staging 及任何其他环境缺少密钥时返回 HTTP 503，不创建用户、不发券、不签发令牌。
- 已配置密钥时必须经微信 code2Session 验证；无效 code、缺失或空 openid 返回 HTTP 400，不回退到模拟身份。
- H5 短信发送、验证码验证、登录会话和会员动态核验保持原有规则；本修复不删除历史 `dev_` 用户或修改既有用户/订单。
- 验证使用隔离内存库和真实应用 HTTP；微信外部响应在测试中替代，不向生产发送登录写探测。生产发布由总控协调，现场验收单独记录。
