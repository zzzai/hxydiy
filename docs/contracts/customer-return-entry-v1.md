# CUSTOMER-RETURN-ENTRY-01：顾客固定回访入口

仅顾客H5导航语义，无后端API、身份、价格或占用合同变化。

- 固定入口为同源根路径 `/?store=<门店>&view=return`。从新URL构造，仅允许store/view，不携带seat、source、qr、session、cart、token、auth、report、项目、hash或浏览器旧访问凭据。
- `view=return`优先进入个人中心，即使输入夹带旧seat/session也忽略并清理。裸门店URL无seat/qr/session/project且非kiosk时同样回访；`view=menu`保留到店选位流程，项目分享保留原详情入口，实际项目选择仍须服务位核对。回访不读取旧选单位点记录、不自动POST入口/占用/选单、不推断床位或复用旧共享草稿。
- 当前有效手机号登录复用，主动退出清除登录且不恢复旧token；本人报告及独立健康授权、撤回/失效/迟到响应处理不变。无报告提示仍引导到店检测。
- 首页提示可关闭，关闭偏好只按门店存储一个非敏感标记；我的保存/联系入口常驻。复制结果只宣称复制，不能宣称已收藏；失败提供可手动复制的固定链接及微信收藏指引。
- 联系配置为前端受控门店字典，store=1使用用户确认且解码一致的企微卡地址；其他门店未配置。只接受官方work.weixin.qq.com的ca路径或受限u联系人路径，图片限本地store-contact资产。不接受任意跳转、用户输入、二维码登录凭据或门店间fallback。二维码按精确payload确定性生成，解码须匹配；自愿添加不影响报告/服务，点击不代表添加成功。不新增营销推送或健康画像。
- 周二展示现有menu-20261007约定：有效会员按门店价消费任意主项买一赠一。适用范围、搭配、补差/叠加由门店人工确认，不新增自动赠送或优惠计算。
