# 顾客端项目列表价格颜色层级设计

日期：2026-08-27

## 目标

通过克制的绿色与金色区分普通顾客价格和会员价格，同时保持清晰的主次关系，避免两种价格争抢注意力。

## 范围

- 仅调整顾客端项目列表卡片的价格颜色、字号和字重。
- 不改变价格计算、身份判断、价格顺序、项目详情页、底部选单或结算页。
- 保持价格单行展示，不增加“门店价”“可省”、色块、边框或促销标签。

## 视觉规则

### 匿名顾客与非会员

- 当前普通价格是主价格：使用低饱和品牌绿、20px、较高字重。
- 会员参考价是次价格：使用低饱和金色、11px、较低字重。
- 示例：`¥59  会员 ¥29`。

### 会员

- 会员价是主价格：使用低饱和金色、20px、较高字重。
- 普通价格是参考价格：使用灰绿色、10px、删除线。
- 示例：`会员 ¥29  ¥59`。

## 色彩方向

- 普通价格绿：深、稳、低饱和，不使用高亮翡翠绿。
- 会员价格金：偏沉静的草本金，不使用亮黄或橙金。
- 删除线参考价：灰绿色，降低对比但保持可读。
- 最终色值以现有白色卡片背景下的真实移动端截图为准，并满足正文可读性。

## 响应式与可访问性

- 在 375px、390px、430px 宽度下保持单行。
- 价格不得溢出或遮挡右侧加购按钮。
- 颜色不是唯一身份信号：同时保留“会员”文字、价格顺序和删除线。

## 验收标准

1. 匿名与非会员卡片的普通价格为绿色主价格，会员参考价为金色次价格。
2. 会员卡片的会员价为金色主价格，普通价格为灰绿色删除线。
3. 绿与金均为低饱和色，不产生高亮促销感。
4. 所有收费项目价格保持单行，无溢出、换行或按钮遮挡。
5. 不出现“门店价”“可省”文案。
6. 项目详情页、底部选单和结算页没有变化。
