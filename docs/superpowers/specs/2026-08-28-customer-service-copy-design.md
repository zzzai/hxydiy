# 顾客端服务词汇设计

## 目标

降低顾客理解成本，避免把后台商品分类和配置术语直接暴露在项目列表与详情页。

## 最终词汇

- 分类名称：`更多服务`
- 计费提示：`单次服务`
- 局部推拿提示：`按部位选择`、`可多选`
- 详情页主按钮：`加入本次服务`

## 词汇映射

| 后台/旧词 | 顾客端处理 |
| --- | --- |
| 小项 | 不展示 |
| 固定项目 | 不展示 |
| 可自由搭配 | 不展示 |
| 按次 | `单次服务` |
| 养生小项 | `更多服务` |

采耳和头疗已有明确时长，不额外添加分类标签；拔罐、刮痧和足部精修显示`单次服务`；局部推拿保留`按部位选择`和`可多选`，因为它确实需要顾客选择服务部位。

## 行为约束

- 小项仍可独立加入本次服务。
- 小项详情页不显示偏好配置区，但保留加入按钮。
- 局部推拿继续支持按部位选择和多选。
- 不修改价格、项目名称、后端菜单合同或选单数据结构。
- 不使用医疗诊断、治疗或夸大效果表述。

## 验收标准

- 顾客端项目列表不出现`小项`、`固定项目`、`可自由搭配`、`按次`。
- “更多服务”分类可正常滚动定位。
- 拔罐、刮痧、足部精修显示“单次服务”。
- 小项仍能进入详情并加入本次服务。
- 其他主项目的“可按需加选”说明不受影响。
