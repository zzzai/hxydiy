# 技师端人体标注服务记录实施计划

**目标：** 将 v4 身体状况从文字按钮升级为手机端正反面人体点位标注，支持多部位分别记录顾客自述与本次处理。

**产品与契约：** 以 `docs/product/technician-body-map-prd.md` 和 `docs/contracts/service-reference-v4.md` 为准；生产现场验收执行 `docs/operations/technician-body-map-field-acceptance.md`。

**交互：** 进入“记录身体相关情况”后依次完成：选部位（人体正反面）→ 选顾客自述情况 → 选当前状态 → 选本次处理。已选部位在底部清单中可编辑或删除；保存前继续走顾客确认摘要。

**安全边界：** 不使用疾病或诊断词；“肩周炎”等展示为“顾客自述肩部不适”，原话不进入历史安全摘要和当前画像。

## 任务

1. 先为人体点位映射与 v5 载荷增加失败测试：肩、膝等点位映射为稳定 `region + side` 编码；每条同时保存 `context`、`current_state`、`session_handling`，未知值、非法侧别、重复点位与超量被拒绝。
2. 扩展 v5 后端合同与 taxonomy；保留已发布 v1–v4 字段兼容，身体条目仍不进入 `customer_profile_current`。
3. 新增可访问的 SVG 正反面人体点位组件；点击可选/取消，底部清单按部位编辑。
4. 将原“身体状况”抽屉替换为四步流程，保存前摘要只显示“需服务前再确认”。
5. 完成后端合同、前端测试、类型检查、生产构建、移动 390×844 截图验收；通过 PR、主干门禁、发布和健康检查后再声明生产完成。
