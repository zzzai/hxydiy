## 当前业务边界

- 智慧宝负责真实开沙发、开房间、派钟、离位、清洁和物理资源释放。
- DIY 负责扫码选位、电子菜单、价格与会员识别、提交选单、确认服务、服务结束、评价、技师画像记录和审计。
- DIY 普通服务位操作仅保留“确认服务”和“服务结束”。
- 项目预计结束超过 30 分钟仍未结束时，DIY 自动关闭自身占用并记录审计。
- 已生成智慧宝履约单的记录不由 DIY 自动释放。

## 当前产品事实

- 17 个实际服务位：8 个大厅沙发、9 个房间床位。
- 正式菜单：12 个项目，包含门店价、团购价和会员价；拔罐、刮痧按次计费。
- 会员登录后直接使用最低会员价，不领券；优惠券只面向符合条件的非会员。
- 技师可在服务后使用标签和文字记录顾客画像，包括结节、年龄、职业、体型、性别等。
- 管理员和员工共用同一后台入口，根据角色执行门店范围隔离。

## 产品与验收原则

- 价格展示必须清晰呈现门店价、会员价和节省金额。
- 不夸大功效，不制造健康焦虑，不强推会员卡。
- 自动化回归不等于真实营业验收。
- 发布前必须完成测试、构建、数据库备份、Manifest 校验、原子切换、健康检查和关键线上流程验证。
- `Refine + Ant Design` 是后续后台结构化整理方向，不代表现有 React + Ant Design 生产后台已经迁移完成。
