# 券运营门店真实验收清单（2026-11-13）

## 使用边界

- 执行人：总部运营 + 门店店长 + 两位已同意的验收顾客（A/B）。
- 使用门店已约定的验收账号和一张新生成的验收海报；本清单不授权自行创建、补发或核销生产测试券，不发送真实短信/营销消息。
- 旧顾客、旧券、旧订单、旧会员记录只读；不得为了验收改写历史数据。
- 截图/录屏必须遮挡完整手机号、券码、顾客姓名和其他个人信息，再放入约定证据目录。
- 自动化测试不能替代真实手机、摄像头、现场本人核对和门店人员签字。
