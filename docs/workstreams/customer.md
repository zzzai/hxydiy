# 顾客端工作流

## 负责范围

- 顾客扫码进入、门店与服务位绑定。
- 菜单、项目详情、门店价/团购价/会员价和节省金额。
- 匿名选单、会员登录、提交给前台、服务状态查看和评价。
- 顾客端移动体验、无障碍、刷新/返回/断网恢复和回归测试。

## 明确不做

- 技师派单、接单、开房、离位、清洁和物理资源释放。
- 管理后台权限模型和运营配置页面。
- 智慧宝资源状态的写入。

## 当前任务

- 状态：当前生产运行正常；本次技师服务参考发布未改变顾客端交互
- 负责人：顾客端窗口
- 开始前读取：`../CONTEXT-MANIFEST.md`、`../CURRENT-STATE.md` 和本文件

## 服务参考跨端边界

- 顾客端当前不直接管理或展示技师服务参考标签。
- 未来如增加顾客确认入口，必须读取后端提供的版本化标签契约，不在顾客端另建标签字典。
- 不得将结构化服务参考转换成普通用户标签，也不得在前端推断顾客画像。

## 跨端变更规则

涉及 API 字段、价格、服务状态、服务位绑定或提交契约时，在同一个 PR 中更新实现、合同测试、`TEAM-MEMORY.md` 和相关 contract；完成后在本文件记录测试结果和交接事项。

## 验证要求

- 顾客端测试必须通过。
- 顾客端生产构建必须通过。
- 会员、非会员、匿名三种身份均需验证。
- 线上发布必须记录 release、Manifest、健康检查和待现场验收项。
