# 顾客端 H5 测试矩阵

更新时间：2026-08-28

## 目标与边界

本矩阵验证荷小悦顾客端从扫码进入、选购、身份与价格识别、提交后的服务状态到评价入口的完整前端行为。

- 自动化测试可以验证软件链路，不能替代门店真实营业验收。
- 智慧宝负责真实开沙发、开房、派钟、离位、清洁和物理资源释放，不纳入顾客端验收动作。
- 生产环境只执行只读检查；提交选单、确认服务、服务结束、评价等写操作仅使用门店授权的测试服务位和测试账号。

## L4 门店授权闭环

1. 用授权的测试服务位扫码进入，确认位置标签正确。
2. 以匿名、非会员、会员各走一次价格识别；会员不领券。
3. 选择一项服务和一项可选内容，核对详情价、底部整单价与提交清单。
4. 提交后返回菜单并刷新，确认草稿不回填。
5. 技师端确认服务，顾客端在一个轮询周期内变为“服务中”。
6. 技师端服务结束，顾客端显示评价入口；提交一次授权测试评价。
7. 复核顾客端到店记录、技师端服务记录与后台审计的服务位、项目、状态、操作者和时间一致。
